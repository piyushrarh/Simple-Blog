# Simple Blog Website

A simple blog website developed using HTML, CSS, and JavaScript.  
This project allows users to add and view blog posts with data stored using browser localStorage.

---

## Project Description

The Simple Blog Website is a frontend application where users can create blog posts by entering a title and content.  
All posts are displayed dynamically and remain saved even after refreshing the page.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

---

## Features

- Add blog posts
- Dynamic display of posts
- Persistent data storage
- Simple and clean user interface
